# 0014. Clock chip: RV-3028

- Status: Proposed
- Date: 2026-11-02

## Decision

Micro Crystal RV-3028 breakout on I2C as the timekeeper; NTP corrects it daily.

## Alternatives rejected

DS3231 module; ESP32 internal RTC only.

## Rationale

Nanoamp draw with ppm-level accuracy. Common DS3231 modules waste 100+ uA on their LED and charging circuit. The internal RTC drifts too much to be the only clock in an alarm clock.
