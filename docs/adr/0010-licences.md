# 0010. Licences

- Status: Proposed
- Date: 2026-11-02

## Decision

Firmware GPL-3.0-only, enclosure CERN-OHL-S-2.0, docs CC BY-SA 4.0.

## Alternatives rejected

MIT firmware.

## Rationale

Common ESP32 audio libraries are GPL-3.0; MIT firmware would be misleading. Recheck when dependencies are pinned.
